What is there while a page is written, and not once it is built: a note to
check something, two versions of a paragraph, a question for later. It shows
set apart, marked as a draft; `whiteboard build` leaves it out (it is in the
build's `skip` by default). The label is optional.

```markdown
:::draft[Check with the API]
Is `wait` really the only way to get answers?
:::
```
