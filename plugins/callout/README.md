A highlighted box with an optional title. Pick the type with `{type=…}` or the
class shorthand `{.warning}`: `note` (default), `tip`, `success`, `warning`,
`danger`, `question`.

```markdown
:::callout[Heads up]{.warning}
Solid 2 is a release candidate; APIs can still move.
:::
```
